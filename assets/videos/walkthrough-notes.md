# Opening hero animation

Uses both user-supplied Sports Complex images, preserved in assets/images as sports-front-original.png and sports-aerial-original.png.

Rendered a roughly five-second (4.75s encoded) silent 1920×800 WebM with slow source-image push-in, lateral drift and cross-dissolves between the entrance and aerial views. This is an animated presentation of the supplied stills, not a newly generated 3D walk-through. The final dissolve returns to the opening view for looping. Size: approximately 936 KB.

Replaces the opening hero illustration, based on the request to show it when the website opens. The featured Nexus project retains its own imagery so the Sports Complex is not mislabeled. Video is contained in an adaptive 2.4:1 frame; desktop uses a left-side scrim for text legibility, while mobile puts the frame below the headline. Poster is local. Existing playback arbitration, visibility pausing and reduced-motion support remain active.

Checked autoplay, mute, looping, pause control, reduced motion, and sizing at 320, 390, 768 and 1440 pixels. No horizontal overflow or script errors observed.
